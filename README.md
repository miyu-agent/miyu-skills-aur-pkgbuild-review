# AUR package review

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This is a skill package for Miyu. It provides one skill, `aur-pkgbuild-review`, and one tool, `aur_review`. Its purpose is to have the AI check an AUR package's PKGBUILD, install scripts and recent commits before you install it.

The review method and the rating rules follow `pac` from [shorin-pac](https://github.com/SHORiN-KiWATA/shorin-pac) (`prompts/aur-review.md`, plus the evidence collection and rating in `bin/pac`): **the AI only reports signals backed by evidence from the source, and the script computes the rating by fixed rules**; if the line the AI quotes cannot be found in the source, a malicious signal is downgraded to suspicious, and any other signal does not count.

## The `aur_review` tool

The tool takes these parameters:

| Parameter | Description |
|---|---|
| `action` | The operation to perform: `collect` (the default) collects the evidence; `score` rates the signals the AI reports. |
| `package` | The name of the AUR package. |
| `findings` | For `score` only: an array of signals, each with `category`, `file`, `evidence` (one line copied word for word from the source) and `summary`; pass `[]` if nothing was found. |
| `intent`, `notes` | For `score` only: what the package installs, and a sentence or two of warning for the user. |
| `format` | The output format: `md` (the default) or `json`. |

`collect` gathers the following: the AUR RPC metadata; a clone of `https://aur.archlinux.org/<pkgbase>.git` (without `git`, it falls back to a cgit snapshot, and the history is marked unavailable); the `git` history (at most 128 entries); the full diffs of the 3 most recent commits (at most 48 KiB); the trust background (a new package or a new committer counts as weak, while at least a year old with 50 votes counts as strong); hosts that appear in the PKGBUILD's `source` but not in `.SRCINFO`; and the full text of every file (binary files, non-UTF-8 files and links get metadata only). If there are more than 128 files, a single file over 128 KiB or more than 512 KiB in total, the tool does not review the package and reports an error instead. The evidence is stored in `MIYU_CACHE_DIR`, and `score` uses this evidence to verify quotes.

The rating rules are: any verified malicious signal → high; suspicious signals in two or more categories → high; suspicious signals in one category with weak trust → high; suspicious signals in one category → medium; only hygiene items with weak trust → medium; fetching unpinned dependencies at build time without strong trust → medium; everything else → low.

## Notes

Keep the following in mind when you use the skill:

- The review is read-only: the tool does not build or install the package, and does not run anything in it. Whether to install is the user's decision; after the review, the AI gives the `paru -S`/`yay -S` command for the user to run.
- The tool needs network access to `aur.archlinux.org`; `git` is optional.
- The tool uses only the Python standard library.
